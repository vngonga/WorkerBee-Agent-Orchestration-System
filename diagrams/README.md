# WorkerBee Diagrams

This folder contains visual diagrams that explain the WorkerBee
multi-agent orchestration system.

The diagrams are intended to make the project architecture and workflow
easier to understand for technical and non-technical readers.

## Available Diagrams

- `workerbee-architecture.png` - High-level WorkerBee system architecture
- `workerbee-workflow.png` - End-to-end WorkerBee execution workflow

Additional diagrams may be added as the project documentation evolves.
